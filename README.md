# my-portfoilio

Persönliches Portfolio mit Projekten, Skills und Kontaktmöglichkeiten.

## Skills

Die [Skills-Seite](skills/index.html) zeigt Hard Skills mit kurzen Beschreibungen
und Angaben zur Erfahrung sowie Soft Skills zur Arbeitsweise. Die Darstellung
passt sich an mobile Geräte und den Hell-/Dunkelmodus an. Alle Beschreibungen
sind auf Deutsch, Englisch, Französisch und Italienisch verfügbar.
